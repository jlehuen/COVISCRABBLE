================================================================================
                      C O V I - S C R A B B L E
                           QUICKSTART GUIDE
================================================================================

Welcome to COVI-SCRABBLE!
This is a networked multiplayer Scrabble game using a Client/Server architecture.
No Python installation is required on your computer to play.

--------------------------------------------------------------------------------
1. PLAYING A LOCAL GAME (ON THE SAME COMPUTER)
--------------------------------------------------------------------------------
1. First, start the SERVER:
   - Double-click on "CoviScrabble-Server" (or run it in a terminal).
   - A console window opens confirming that the server is listening on port 1234.
   - Keep this window running in the background.

2. Start the CLIENT for each player:
   - Double-click on "CoviScrabble".
   - The identification prompt will appear.
   - Pre-configured test credentials:
       * Player 1: Login = toto   |   Password = toto
       * Player 2: Login = titi   |   Password = titi
   - Click "OK" to authenticate and connect.

3. Play:
   - Click "Start Game" on either client.
   - 7 tiles are dealt to each player's rack.
   - The active player can now drag and drop tiles onto the board.
   - The opening word MUST cover the center star square (7, 7).
   - Click "Validate" to submit your word, score points, and pass the turn.

--------------------------------------------------------------------------------
2. PLAYING OVER A LOCAL NETWORK (BETWEEN MULTIPLE COMPUTERS)
--------------------------------------------------------------------------------
1. The host starts "CoviScrabble-Server" and notes their local IP address
   (displayed in the server console, e.g. 192.168.1.25).

2. Other players connect to the host by specifying its IP address:
   * On Windows (Command Prompt / PowerShell):
       CoviScrabble.exe -host 192.168.1.25 -port 1234
   * On macOS (Terminal):
       ./CoviScrabble -host 192.168.1.25 -port 1234
   * On Linux:
       ./CoviScrabble -host 192.168.1.25 -port 1234

--------------------------------------------------------------------------------
3. COMMAND LINE OPTIONS
--------------------------------------------------------------------------------
* Client:
    -host <address> : Server IP address or hostname (default: localhost)
    -port <number>  : Server TCP port (default: 1234)
    -fr / -en       : UI language (default: EN)

* Server:
    -port <number>  : Listening TCP port (default: 1234)
    -fr / -en       : Dictionary and letter bag language (default: EN)
    -data <module>  : User credentials module (default: database)
